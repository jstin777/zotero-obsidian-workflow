# Changelog

## 0.1.0 — 2026-11-06

Initial Mac-first public template: local Zotero annotation/status sync, protected local review, reading and capture dashboards, Chrome Connector and Scite setup, synthetic demonstration, optional Marker/QMD/Codex modules, opt-in launchd scheduling, recovery guards, offline checks and documentation.

See `docs/compatibility.md` for validated configurations and incomplete live integration checks. This initial release is a preview until those checks are completed independently on another Mac.
